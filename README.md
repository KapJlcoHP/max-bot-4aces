# МедМаршрут — бот + мини-ап для платформы MAX

Хакатон MAX, команда 4Aces, кейс «Забота о людях».
Мини-ап помогает пройти медицинский маршрут: подготовка к приёму, документы,
анализы, напоминания, дневник давления, семейный доступ.

> **Честность данных:** все персональные данные (пользователь «Анна», участники
> семьи, показатели давления) и справочник организаций — синтетические
> демо-данные. Источники и что понадобится для реальной интеграции —
> `content/SOURCES.md`. Метка «ДЕМО-ДАННЫЕ» стоит в интерфейсе справочника.

## Стек

- **Бэкенд:** Python 3.12, FastAPI + uvicorn, SQLAlchemy 2.0 + SQLite, pydantic v2
- **Бот:** [maxapi](https://love-apples.github.io/maxapi/) (long polling в dev)
- **Мини-ап:** Vite 6 + React 19 + TypeScript, MAX Bridge (`window.WebApp`) и компоненты MAX UI (`@maxhub/max-ui`)
- Аутентификация мини-апа — подписанный `initData` (HMAC-SHA256), проверяется на сервере

## Структура

```
zabota/
├── core/          # ядро: config, модели БД, сид демо-данных, pydantic-схемы
├── bot/           # адаптер чат-бота (maxapi): /start, /app, /help + кнопка мини-апа
├── server/        # FastAPI: REST /api/v1 (+ статика собранного мини-апа)
├── content/       # контент вне кода: каталог ситуаций, сценарии маршрутов, организации
├── web/           # мини-ап (React): мобильные экраны и десктопная раскладка по макету МедМаршрут
├── certs/         # российский CA-бандл для Bot API (пригодится в Docker)
├── run_api.bat    # запуск API: http://127.0.0.1:8000
├── run_web.bat    # dev-сервер мини-апа: http://localhost:5173 (нужен запущенный API)
└── run.bat        # запуск бота (long polling)
```

## Запуск в dev-режиме (3 консоли)

1. **API** — `run_api.bat` → http://127.0.0.1:8000 (OpenAPI: `/docs`)
2. **Мини-ап** — `run_web.bat` → http://localhost:5173
   (первый раз: `cd web && npm install`)
   В обычном браузере мини-ап работает в **демо-режиме** (жёлтая плашка):
   нужен `DEV_BYPASS_AUTH=true` в `.env`.
3. **Бот** — `run.bat` (токен уже в `.env`). В MAX: найти @t24_hakaton_max_bot →
   «Старт» → кнопка «🏥 Открыть МедМаршрут» запускает мини-ап.
   ⚠️ Экземпляр бота должен быть ровно один.

Прод-сборка мини-апа: `cd web && npm run build` → FastAPI раздаёт `web/dist`
на `/` — на сервере достаточно одного процесса API.

## Что работает

- **Маршрут:** 12 шагов «Подготовка к приёму у терапевта», прогресс, отметка
  выполнения с датой и заметкой → показ следующего шага; финал — «Маршрут завершён»
- **Каталог ситуаций:** 8 жизненных ситуаций → выбор создаёт новый маршрут
  (сценарии шагов и чек-листов — в `content/scenarios.json`, правится без кода)
- **Чек-лист документов:** группы «нужно собрать / собрано», счётчик,
  переключение кликом, добавление своих документов
- **Организации:** демо-справочник, поиск, фильтры по типу, звонок (tel:),
  «Показать путь» (Яндекс.Карты)
- **Напоминания:** предстоящие/прошедшие, тумблеры; кнопка «Напомнить» на шаге
  создаёт напоминание
- **Дневник здоровья:** график давления (сист./диаст.), история, добавление
  записи с валидацией; оценка «Норма / Выше нормы» — ориентировочная
- **Семейный доступ:** участники с ролями, добавление (демо)
- **Профиль:** переключатель уведомлений, «О приложении», политика
- **Бот:** `/start`, `/app`, `/help`; диплинк `?startapp=<экран>` открывает
  мини-ап на нужном экране

## API

REST `/api/v1`: `/me`, `/me/settings`, `/catalog`, `/route`, `/route/start`,
`/route/steps/{id}/complete`, `/checklist*`, `/orgs*`, `/reminders*`,
`/health/records*`, `/family*`, `/health`. Интерактивная документация — `/docs`.
Аутентификация: заголовок `X-Max-Init-Data` с подписанным initData из MAX Bridge.
